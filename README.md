# 칼바람 봇 (HowlingAbyss Bot)

게임 소모임의 내전과 대회를 빠르게 진행하기 위해 만든 디스코드 봇입니다.

소모임 임원으로 활동하며 내전을 열 때마다 팀 나누기, 챔피언 분배, 진영 정하기를 사람이 직접 하느라 시간이 걸리고 공정성 문제가 생기는 것을 보고 직접 개발했습니다. 실제 소모임 내전과 대회에서 사용했습니다.

## 주요 기능

* **팀 자동 구성**: 명령어를 입력한 사람이 접속한 음성 채널의 인원을 무작위로 두 팀으로 나눕니다.
* **칼바람 챔피언 랜덤 분배**: 각 팀에 지정한 수만큼 챔피언을 중복 없이 무작위로 뽑습니다. 결과는 스포일러 태그로 가려져 상대 팀 챔피언을 미리 볼 수 없습니다.
* **진영 / 공수 추첨**: 두 팀 대표 이름을 받아 블루·레드 진영, 공격·수비와 맵 선택권을 정합니다.
* **오버워치 맵 추첨**: 내전에서 쓰지 않는 맵을 제외한 목록에서 무작위로 맵을 고릅니다.

## 명령어

|명령어|설명|
|-|-|
|`!명령어`|사용 가능한 명령어 목록을 보여줍니다.|
|`!팀섞기`|현재 음성 채널 인원으로 2개의 팀을 만듭니다.|
|`!칼바람 (num)`|각 팀에게 num개의 챔피언을 랜덤하게 뽑습니다.|
|`!진영 이름1 이름2`|레드와 블루 진영을 정합니다.|
|`!공수 이름1 이름2`|공수와 맵 선택권을 정합니다.|
|`!오버워치`|오버워치 맵 중 하나를 랜덤으로 선택합니다. (특정 맵 제외)|
|`!오버워치목록`|추첨 대상 오버워치 맵 목록을 보여줍니다.|
|`!업데이트`|최근 업데이트 내역을 보여줍니다.|
|`!종료`|봇을 종료합니다.|

## 개발 환경

* Python 3
* discord.py

## 실행 방법

```bash
pip install discord.py
python main.py
```

보안을 위해 디스코드 봇 토큰은 저장소에 포함하지 않았습니다. 실행 전 `main.py`의 `bot.run('api 보안키')` 부분에 본인의 봇 토큰을 넣어 주세요.

## 파일 구성

```
├── main.py           # 봇 실행 및 명령어 처리
├── howlingabyss.py   # 칼바람 챔피언 목록 및 랜덤 추출
└── overwatch.py      # 오버워치 맵 목록 및 랜덤 추출
```
